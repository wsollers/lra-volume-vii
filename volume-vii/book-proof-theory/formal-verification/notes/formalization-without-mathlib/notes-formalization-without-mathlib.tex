\begin{remark*}[Scope]
The no-mathlib track is reserved for foundations built from
the project primitives. Its purpose is different from the mathlib track. Here
the work is not to discover an existing API, but to decide the representation,
state the primitive laws, and prove the first usable interface theorems from
those laws.
\end{remark*}

\begin{remark*}[Contrast with metric spaces]
Metric spaces are not the right first no-mathlib target for this volume. The
mathlib library already supplies the intended metric-space interface, and the
formalization goal is to learn how to use it. The no-mathlib track should
instead follow the set-theoretic material being developed separately, where
the point is to construct the objects and proofs from the local foundation.
\end{remark*}
